# Academic Project Report — Outline

**Title:** AI-Powered Venture Capital and Startup Collaboration Platform Using Deep Learning and Data Analytics

**Product:** Venture AI

---

## 1. Abstract
- Problem: fragmented startup–investor discovery; shallow evaluation; opaque pitch quality
- Solution: three-model AI platform integrated with a full-stack web application
- Approach: multi-output neural network for potential/risk, two-tower recommender, BERT classifier
- Result: working end-to-end system on synthetic development data
- Explicit statement: results are on synthetic data and do not represent real investment performance

## 13. Dataset Description
- **Synthetic** dataset, ~300 unique startup records
- 303 rows, 3 duplicates detected and removed
- Features: financial, traction, team, funding, stage, industry, business model
- Split: 70% / 15% / 15%

## 14. Data Preprocessing
- Deduplication by `startup_id`
- Missing value strategy
- Categorical encoding (industry, business_model, startup_stage)
- Feature engineering: revenue_per_customer, users_per_team_member, growth_adjusted_runway, funding_to_revenue, burn_to_revenue
- Persistence of the fitted preprocessor (`preprocessor.pkl`)

## 15. Deep Learning Models

### 15.1 Startup Potential & Risk
- MLP architecture
- Multi-output: regression + classification
- Custom training loop with per-sample class weights
- Metrics: MAE 4.95, R² 0.546, accuracy 64.4%, ROC AUC 0.780

### 15.2 Two-Tower Recommendation
- Startup tower, investor tower
- L2-normalized embeddings, dimension 32
- Cosine similarity scoring
- Metrics: Precision@5 0.019, Recall@5 0.017, NDCG@10 0.026, Hit Rate@10 0.238

## 16. Recommendation System
- Data: investor–startup interaction matrix (synthetic)
- Training objective: binary crossentropy on `sigmoid(5 · dot)` scaled scores
- Serving: rank candidate startups for a given investor
- Cold-start limitations

## 17. BERT Pitch Deck Analyzer
